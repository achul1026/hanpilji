# 한필지 웹사이트 공개하기 (Google Cloud Run)

이 문서대로 하면 한필지 웹이 `https://hanpilji-…run.app` 같은 주소로 누구에게나 열립니다.
**회사 PC · 회사 계정이 아니라 개인 Google 계정**으로 하세요. 휴대폰이나 집 맥북 브라우저면 됩니다.
설치할 프로그램은 없습니다(전부 웹 화면에서 누름).

## 0. Cloud Run이 뭔가요, 정말 무료인가요

- **Cloud Run** = 구글이 대신 서버를 켜 주는 서비스입니다. 우리가 만든 웹(Dockerfile로 묶은 것)을 올려 두면,
  누가 접속할 때만 켜지고 아무도 없으면 꺼집니다. 서버 관리 · 보안 패치 · 인터넷 주소(https)를 구글이 맡습니다.
- **무료 한도(매달)**: 요청 200만 건, CPU 18만 vCPU-초, 메모리 36만 GiB-초.
  시험 운영(하루 방문자 수십~수백 명)은 이 안에 충분히 들어갑니다. 질문 하나에 서버가 10~30초 일하므로
  매달 수천 개 질문까지 무료 범위입니다.
- **카드는 등록해야 합니다.** 결제 계정을 만들어야 쓸 수 있습니다. 대신 새 계정은 **90일 · $300 무료 체험**이 붙고,
  체험 중에는 직접 「유료 계정으로 업그레이드」를 누르기 전까지 **카드에서 돈이 나가지 않습니다.**
- 그 밖에 아주 작게 붙을 수 있는 것: 이미지 보관(0.5GB까지 무료, 넘으면 GB당 월 약 140원), 국내로 나가는 데이터
  (화면이 작아 월 몇십~몇백 원 이하). 예상 합계는 **월 0원 ~ 1,000원 미만**입니다.
- **진짜 비용은 Cloud Run이 아니라 답을 만드는 AI(Anthropic) 요금입니다.** 질문 하나에 대략 100~400원(추정,
  도구를 몇 번 부르느냐에 따라 다름)이 개인 Anthropic 키로 나갑니다. 그래서 웹에 다음 제한을 넣었습니다.
  - 방문자(IP)마다 한 시간에 질문 30개
  - 모든 방문자를 합쳐 24시간에 질문 50개(`HANPILJI_WEB_DAILY_LIMIT`로 바꿈). 최악이어도 하루 약 2만 원
  - 서버가 쉬다가(아무도 안 오면 약 15분 뒤 꺼짐) 다시 켜지면 이 수가 0부터 다시 셉니다.
    그래서 **꼭 3단계의 Anthropic 월 사용 한도를 정해 두세요.** 그게 진짜 안전장치입니다.

### 다른 무료 호스팅과 비교

| | Cloud Run (추천) | Render 무료 | Hugging Face Spaces 무료 |
|---|---|---|---|
| 카드 | 필요(체험 중엔 청구 없음) | 필요 없음 | 필요 없음 |
| 서버 위치 | **서울** | 싱가포르 · 미국 · 유럽 | 미국 |
| 쉬다가 첫 접속 | 2~5초 | **약 1분** 기다림 | 48시간 안 쓰면 잠듦, 깨우는 데 수십 초 |
| 그 밖에 | 자체 도메인 무료 연결 | 월 750시간 | 공개 Space는 코드가 남에게 보임 |

방문자가 처음 열 때 1분을 기다리면 대부분 나가 버리므로 Cloud Run을 추천합니다.

## 1. Google Cloud 가입 · 프로젝트 만들기 (약 10분)

1. 개인 Google 계정으로 https://console.cloud.google.com 에 들어갑니다.
2. 「무료로 시작하기」(또는 「무료 체험」)를 누르고 국가 「대한민국」, 계정 유형 「개인」, 카드 정보를 넣습니다.
3. 위쪽 프로젝트 선택 → 「새 프로젝트」 → 이름 `hanpilji` → 만들기.
4. **예산 알림**: 왼쪽 메뉴 「결제」 → 「예산 및 알림」 → 「예산 만들기」 → 금액 5,000원, 50% · 90% · 100%에 메일 알림.
   (알림일 뿐 자동으로 멈추지는 않지만, 뭔가 새면 바로 압니다.)

## 2. Supabase에 웹 전용 읽기 계정 켜기 (약 3분)

웹 서버는 관리자(postgres) 대신 `mart`만 읽을 수 있는 `hanpilji_gpt` 계정으로 DB에 붙습니다. 계정은 이미 있고
로그인만 꺼져 있습니다.

1. https://supabase.com/dashboard → 한필지 프로젝트 → 왼쪽 「SQL Editor」.
2. 아래를 붙여 넣고 `여기에-긴-비밀번호`를 새 비밀번호(영문 · 숫자 20자 이상, `@` `:` `/` 는 빼기)로 바꾼 뒤 「Run」.
   ```sql
   ALTER ROLE hanpilji_gpt LOGIN PASSWORD '여기에-긴-비밀번호';
   ALTER ROLE hanpilji_gpt SET default_transaction_read_only = on;
   ALTER ROLE hanpilji_gpt SET statement_timeout = '5s';
   ```
3. 위쪽 「Connect」 → 「Session pooler」 주소를 봅니다. 모양이 이렇습니다.
   `postgresql://postgres.<프로젝트ref>:[YOUR-PASSWORD]@aws-0-ap-northeast-2.pooler.supabase.com:5432/postgres`
   여기서 `postgres.` 를 `hanpilji_gpt.` 로, `[YOUR-PASSWORD]`를 방금 정한 비밀번호로 바꾼 것이
   `HANPILJI_GPT_DSN` 값입니다. 메모장에만 두고 채팅에 붙이지 마세요.

## 3. Anthropic 월 사용 한도 정하기 (약 2분)

1. https://console.anthropic.com → 「Settings」 → 「Limits」(또는 「Billing」 → 「Spend limits」).
2. 월 한도를 정합니다(예: $30). 넘으면 답 대신 「오류」가 나고 돈은 더 나가지 않습니다.
3. 웹 전용 키를 따로 만들면 나중에 끊기 쉽습니다: 「API Keys」 → 「Create Key」 → 이름 `hanpilji-web`.
   이 키는 2026-12-31 만료 예정인 `hanpilji-gpt`와 같은 계정이니 만료 전에 같이 갱신하세요.

## 4. Cloud Run 서비스 만들기 (약 10분, 처음 빌드 3~5분)

1. 콘솔 위쪽 검색창에 「Cloud Run」 → 「서비스 만들기」(Deploy container → Service).
2. 「저장소에서 지속적으로 배포(GitHub)」를 고르고 「Cloud Build 설정」을 누릅니다.
   - 처음이면 API 사용 설정 버튼이 나오니 누릅니다.
   - 「GitHub」 → 개인 GitHub 계정으로 로그인 → 저장소 `achul1026/hanpilji` 선택(앱 설치 화면이 나오면 이 저장소만 허용).
   - 브랜치 `^main$`, 빌드 유형 **Dockerfile**, 위치 `/Dockerfile` → 저장.
     이제 main에 PR이 합쳐질 때마다 자동으로 새로 올라갑니다.
3. 서비스 이름 `hanpilji`, 리전 **asia-northeast3 (서울)**.
4. 인증: **「인증되지 않은 호출 허용」**(누구나 열 수 있게). 결제: **「요청 기반」**(쓸 때만 요금).
5. 「컨테이너, 볼륨, 네트워킹, 보안」을 펼쳐서:
   - 컨테이너 포트 8080(기본값 그대로), 메모리 512MiB, CPU 1
   - 요청 제한 시간 600초(답이 길면 1~2분 걸림)
   - **최소 인스턴스 0, 최대 인스턴스 1** (대화를 서버 메모리에 두므로 1대만. 0이어야 무료)
   - 「변수 및 보안 비밀」 → 환경 변수 추가:

     | 이름 | 값 |
     |---|---|
     | `HANPILJI_LLM_API_KEY` | 3단계에서 만든 키(`sk-ant-…`) |
     | `HANPILJI_GPT_DSN` | 2단계에서 만든 주소 |
     | `HANPILJI_WEB_DAILY_LIMIT` | `50` (하루 전체 질문 수, 필요하면 조정) |
     | `HANPILJI_VWORLD_MAP_KEY` | V-World 운영키가 나오면 추가(없으면 지도는 선만 그림) |

     `HANPILJI_WEB_PUBLIC=1`, `HANPILJI_TRUST_PROXY=1`은 Dockerfile에 이미 들어 있습니다.
     (방문자별 한도를 셀 때 구글이 붙여 주는 방문자 주소를 씀. 올린 뒤 「로그」에서 서로 다른 사람의 접속이
     모두 같은 주소로 찍히면 알려 주세요. `HANPILJI_TRUST_PROXY=2`로 바꾸면 됩니다.)
     (더 조심하려면 키 두 개는 「보안 비밀 참조」로 Secret Manager에 넣어도 됩니다. 비밀 6개까지 무료)
6. 「만들기」. 빌드가 끝나면 위쪽에 `https://hanpilji-xxxxxxxx.asia-northeast3.run.app` 주소가 나옵니다.
7. 휴대폰으로 그 주소를 열고 「도곡렉슬 84㎡ 최근 1년 매매가」를 물어 봅니다.
   안 되면 서비스 화면의 「로그」 탭 내용을 그대로 알려 주세요.

## 5. (나중에) 내 도메인 붙이기

도메인을 사면(가비아 · Cloudflare 등, `.kr` 연 1~2만 원) Cloud Run 서비스 화면 「사용자 지정 도메인」 →
「매핑 추가」에서 연결하고, 안내하는 DNS 값을 도메인 회사 화면에 넣습니다. 인증서(https)는 무료로 자동 발급됩니다.
도메인이 바뀌면 V-World 키의 서비스 URL도 같이 고쳐야 합니다(아래 6단계).

## 6. V-World 운영키 신청 (지도 배경 · 토지 정보용)

지금 쓰는 키는 **개발키**라 공개 웹사이트에는 못 씁니다. 운영키는 심사가 있어 약 열흘 걸리니 미리 신청합니다.
**서비스 URL에는 실제로 사이트가 열리는 주소**를 적어야 하고, 키는 그 주소에서만 동작합니다.
그래서 4단계를 먼저 해서 `run.app` 주소를 받은 뒤 신청하는 순서를 권합니다(도메인을 살 거면 그 주소).

1. https://www.vworld.kr 에 개인 계정으로 로그인합니다(없으면 회원가입, 본인인증).
2. 위쪽 「오픈API」 → 「인증키 발급」(또는 「인증키 신청」).
3. 신청서를 이렇게 채웁니다.
   - 서비스명: `한필지`
   - 서비스 분류 · 유형: 「웹사이트」(기관 · 기업이 아니라 개인)
   - 키 종류: **운영키**
   - 서비스 URL: `https://hanpilji-xxxxxxxx.asia-northeast3.run.app` (4단계에서 받은 주소, 끝에 `/` 없이)
   - 활용 API(체크):
     - **2D 데이터 API**(WMTS · 배경지도 2D) — 웹 지도 배경 타일
     - **NED 국가중점데이터**: **토지특성정보**, **토지이용계획정보** — 지목 · 공시지가 · 용도지역
   - 서비스 설명: 「공공데이터(실거래 · 건축물대장 · 토지이용계획)를 필지 번호로 묶어 근거와 함께 보여 주는
     부동산 정보 웹사이트. 배경지도와 토지 특성 · 이용계획을 화면에 표시하고 출처를 밝힘.」
4. 제출 → 「마이페이지」 → 「인증키 관리」에서 심사 상태를 봅니다. 승인되면 키를 Cloud Run 환경 변수
   `HANPILJI_VWORLD_MAP_KEY`에 넣고(4단계 5번, 「새 버전 수정 및 배포」) 저장하면 지도 배경이 켜집니다.
5. 나중에 도메인이 바뀌면 「인증키 관리」 → 해당 키 → 「수정」에서 서비스 URL을 바꿉니다.

> 상업적 이용 문의 답변은 아직 기다리는 중입니다. 광고 · 유료화 전에는 그 답을 먼저 확인하세요.
